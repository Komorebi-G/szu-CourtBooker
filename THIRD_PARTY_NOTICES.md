# Third-party notices

The project's MIT license does not replace the licenses of dependencies or the bundled runtime. Exact JavaScript versions and source locations are recorded in the two `package-lock.json` files; Android dependencies are recorded in Gradle files.

| Component | License | Usage |
|---|---|---|
| Node.js | MIT and bundled third-party notices | Windows embedded runtime |
| Playwright | Apache-2.0 | Desktop browser login |
| yaml | ISC | Desktop configuration |
| Capacitor | MIT | Android bridge and WebView shell |
| OkHttp / Okio | Apache-2.0 | Android HTTP transport |
| AndroidX | Apache-2.0 | Android application support |
| Kotlin standard library | Apache-2.0 | Android transitive dependency |
| esbuild | MIT | Build-time JavaScript bundler |
| postject | MIT | Build-time Windows executable packaging |
| Gradle wrapper | Apache-2.0 | Android build bootstrap |

Upstream sources: [Node.js](https://github.com/nodejs/node), [Playwright](https://github.com/microsoft/playwright), [yaml](https://github.com/eemeli/yaml), [Capacitor](https://github.com/ionic-team/capacitor), [OkHttp](https://github.com/square/okhttp), [Okio](https://github.com/square/okio), [AndroidX](https://android.googlesource.com/platform/frameworks/support/), [Kotlin](https://github.com/JetBrains/kotlin), [esbuild](https://github.com/evanw/esbuild), [postject](https://github.com/nodejs/postject), [Gradle](https://github.com/gradle/gradle).

Release assets include a separate third-party license archive. The Windows payload also retains license files present in bundled JavaScript packages. No school website content, account credentials, Android SDK, JDK, or browser installation is distributed as project source.
