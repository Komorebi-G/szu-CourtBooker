# v0.2.0 · 首个公开预发布版本

Windows 桌面版与 Android 前台版，共用预约核心。此版本为测试预发布，学校接口兼容性和设备唤醒仍需实际环境验证。

## 下载

- `SZU-CourtBooker-Windows-x64.exe`：Windows x64，自带 Node 运行时，无需安装依赖；没有黑色终端。
- `SZU-CourtBooker-Android-debug.apk`：Android 7.0+，开发签名测试包。无需电脑或服务器，必须保持前台执行。
- `SHA256SUMS.txt`：校验下载文件。
- `LICENSES.zip`：项目及第三方许可证。

## 功能

- 多账号独立保存，任务选择用户，登录 JSON 导入/导出。
- Android 内置学校登录窗口，自动获取 Cookie，验证身份后保存；取消或错号不覆盖原账号。
- 今天至未来第七天、多候选时段、数字场地优先级、可选优先同场。
- 新任务默认 0.1 秒轮询；同一执行批次内，同账号/项目/日期成功两个时段后停止。
- Windows 系统任务调度与日志持久化，关闭管理网页后继续执行。
- 桌面开始时间后 30 分钟内补跑/恢复，保留已成功时段，只尝试剩余时段。
- 工作区拆分为 `desktop/`、`mobile/`、`shared/`，保留旧入口以兼容已有调度路径。

## 注意与升级

Windows EXE 未做代码签名；Android 使用开发签名，尚未完成真机学校登录、验证码和预约验收。Android 当前内部版本为 1.2（versionCode 3），对应此统一发行版 v0.2.0。

Windows 更新前停止正在执行的任务，再替换固定位置的 EXE。Android 同签名旧版可覆盖安装；不同签名可能需要卸载，卸载会清除本地数据，请先导出。

学校接口与限制可能变化，工具不保证预约成功。不自动付款或退订；未知请求结果请先到学校核对。关机不能执行，休眠唤醒取决于系统配置；Android 切后台中断，返回不会自动重跑。

已知开发依赖告警：Capacitor CLI 的 `xcode/uuid` 链有 3 项 npm 中等级告警，未强制降级框架；见仓库 `SECURITY.md`。

包内不包含账号、Cookie、任务或订单。请勿公开上传登录 JSON。
