运行、休眠和清理说明

任务会提前两分钟准备，到设定时间才提交。开始时间后30分钟内允许补跑或恢复，持续时间从本次实际开始重新计算；已成功时段不再提交。超过30分钟不补跑。中断时结果未知的请求会先核对学校记录，无法确认的时段跳过并提示。

Windows 会请求休眠唤醒，并在重新登录后恢复符合条件的任务。请保持用户登录、允许唤醒定时器并联网，关机时不能执行。旧版已登记任务需在新版停止后重新安排，才有登录恢复触发。Linux 用户定时器需要保持登录和唤醒。

“停止并取消定时”会停止后续尝试，等待已发出请求的结果，手动停止不会自动恢复。“删除”移除系统定时项，把日志移入回收目录。它们都不会取消学校已经成功的预约。
